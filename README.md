# komet-stamped-document-plugin

The stamped document as a Komet plugin: AsciiDoc documents kept in git, read and edited line by
line in Komet with each line's STAMP, on a block surface that pages and prints.

Komet ships it with or without the assistant (komet-claude-plugin). The assistant and the profile
plugins — decision tree, ANF, calculator, complex concept — plug into it through its structured
block kinds (`StructuredBlockKind`).

Built as a member of the `ike-komet-wsr` working set. Tracked in
[IKE-Network/ike-issues#1351](https://github.com/IKE-Network/ike-issues/issues/1351).
